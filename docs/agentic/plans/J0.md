# J0 plan (Foundations)

Produced by the planner on 2026-10-28. Source of truth for J0 task ids (T1…T34).
Every package in `go list ./...` must reach 70% coverage (packages without tests count
as 0%); normalize, store, secrets, fsx and httpx must reach 85%.

## Kit findings that shape the plan
- `scripts/leakcheck.sh` can never pass: under `pipefail`, grep exits 1 on zero hits and
  kills the script; a missing `testdata/` makes grep exit 2. Fixed in T3.
- `CANARY_FILE` / `ART_DIR` are relative but `go test` runs in each package dir: the
  Makefile exports absolute paths; testsecrets falls back to the module root.
- forbidigo applies to `_test.go` too: tests use fsx and clock, never `os.WriteFile`,
  `os.MkdirAll`, `time.Now`.
- `//nolint` / `#nosec` need an issue number: design so none are needed (`os.Root` in
  fsx, constant exec argv).
- guard.sh rejects any Bash command containing the bare words `pass`, `BW_SESSION`,
  `.facto/`, `t.Skip`: don't grep for them from the shell.
- `internal/vault` is J1 (with its ADR); its 85% gate applies automatically once it exists.
- `gopkg.in/yaml.v3` is archived: ADR 0003 evaluates `go.yaml.in/yaml/v3`.
- No CI review bot (claude-review is not used); reviewer + security-auditor run locally.
