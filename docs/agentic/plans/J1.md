Produced by the planner on 2026-10-29, updated with Florian's decisions the same day.
Source of truth for J1 task ids (T1…T32). One task = one commit. Every code task runs
test-writer → implementer → reviewer → security-auditor unless stated otherwise.

## Starting point (what J0 left)
- No `internal/browser`, `internal/vault` or `connectors/` yet. `internal/vault:85` is
  already in `COVER_GATES`; T10 adds `internal/browser:85`.
- `connector.Env` has `any` placeholders (`SecretResolver`, `Prompter`, `BrowserPool`,
  `Session`); no session-restore API.
- `cmd/facto/collect.go:241` refuses every enabled connector; the secret resolver is not
  wired into `collect` (SEC-J0-22).
- `httpx` allows port 443 only and refuses unlisted IP literals; it has `Options.RootCAs`
  and `Options.DialContext`. The fake site uses `*.fakeprovider.test:443`, dialled to
  loopback in e2e builds only.
- depguard `network` denies `net/http` in non-test code; `guard.sh` blocks curl/wget, so
  ADR research uses the Go module proxy (`go list -m -json`, `go mod download`).
- `osv-scanner.toml` ignores GO-2026-5932 (openpgp) on the claim "never compiled"; T3
  turns that claim into a lint gate.
- J0 audit gave provisional full marks to categories 2, 3, 9: J1 scores them from zero.

## Decisions (Florian, 2026-10-29)
| Id | Decision |
| --- | --- |
| A1 | Session files are `<connector>.sess` whatever ADR 0009 picks; `docs/spec.md` updated. |
| A2 | Rotation = new per-connector key and nonce on every successful login, crash-safe order. |
| A3 | File key source exists only behind the `e2e` build tag; a check proves the release build lacks it. Production without keyring → ephemeral sessions + warning. systemd-creds deferred to J2 (noted in PROGRESS.md). |
| A4 | Windows only: `--remote-debugging-port=0`, port read from `DevToolsActivePort`, loopback-only (asserted in a test), disposable profile, browser closed right after login. Recorded in ADR 0008 and the threat model as an accepted medium finding; issue opened to retry pipe via `SysProcAttr.AdditionalInheritedHandles`. Linux/macOS: pipe only. |
| A5 | The `otp` ref always resolves to a code, never a seed. |
| A6 | e2e covers non-interactive `needs_login`; the visible relaunch is unit-tested only. |
| A7 | Fake site lives in `test/e2e/*_test.go`, bound to 127.0.0.1. No depguard exemption. |
| A8 | e2e builds accept stdin lines only when `FACTO_E2E_INTERACTIVE=1`. |
| A9 | Planner proposal adopted by the plan (not ruled on explicitly): session restore via `Env.Saved secret.Secret` + optional `Persistable` interface (T5). |
| A10 | Planner proposal adopted by the plan (not ruled on explicitly): Chrome for Testing hash pinned trust-on-first-use (ADR 0008), linux64 installer only in J1, explicit `facto browser install` (no silent download). |
| A11 | Browser blocks off-allowlist hosts by default. Real-site CDNs are added per connector in J2. |
| A12 | Profile under `$XDG_RUNTIME_DIR/facto`, else `<state>/tmp` (0700). Stale profiles in both are swept at startup. |
| A13 | `sessions: ephemeral` deletes an existing session file at startup without reading it, logged once. |
| A14 | e2e scenario list follows GOALS.md plus bad-password, sessions-ephemeral, browser-allowlist. |
